# BlurShield Chrome Extension (Manifest V3)

BlurShield automatically blurs YouTube video thumbnails, Google image search results, general browser images, and running or paused HTML5 videos with customizable hover-to-reveal controls and intensity settings.

## 🚀 How to Install in Chrome / Edge / Brave

1. Download and extract **BlurShield-Chrome-Extension.zip**.
2. Open Google Chrome and navigate to `chrome://extensions/` (or `edge://extensions/` in Edge).
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the extracted folder containing `manifest.json`.
6. Done! Click the BlurShield extension icon in your browser toolbar to adjust settings or toggle blur on/off.

## ⚡ Keyboard Shortcut
Press **Alt + Shift + B** anytime to toggle BlurShield on or off instantly.

## 🛠️ Included Files
- `manifest.json`: Manifest V3 Extension Configuration
- `content.js` & `content.css`: Dynamic DOM observer and CSS filter rules
- `popup.html` & `popup.js`: Extension Control Panel UI
- `background.js`: Service worker, keyboard shortcuts & context menu
- `icons/`: Extension toolbar icons
